Diplom Задание 3

Тесты:

test_main_page.py
Тестирует:
1) переход по клику на «Конструктор»;
2) переход по клику на раздел «Лента заказов»;
3) если кликнуть на ингредиент, появится всплывающее окно с деталями;
4) всплывающее окно закрывается кликом по крестику;
5) при добавлении ингредиента в заказ счётчик этого ингредиента увеличивается.

test_feed_page.py
Тестирует:
1) при создании нового заказа счётчик «Выполнено за всё время» увеличивается;
2) при создании нового заказа счётчик «Выполнено за сегодня» увеличивается;
3) после оформления заказа его номер появляется в разделе «В работе».


Вспомогательные файлы:

data:
ingredients.py - хранит названия всех ингридиентов
urls.py - хранит ссылки на все необходимые тестам страницы сайта

locators:
header_locators.py - хранит локаторы для элементов хэдера общего для всех страниц
main_page_locators.py - хранит локаторы для главной страницы "Конструктора"
feed_page_locators.py - хранит локаторы для страницы "Лента заказов"

pages:
base_page.py - хранит базовые методы для работы всех страниц
main_page.py - хранит методы для работы с главной страницей "Конструктор"
feed_page.py - хранит методы для работы со страницей "Лента заказов"

conftest.py - хранит фикстуры
requirements.txt - хранит библиотеки тестового стенда
